# Forest props

- `prop_checkpoint_shrine_idle.png` 32×64 ×1: an unlit runestone.
- `prop_checkpoint_shrine_activate.png` 32×64 ×6 @10, played once on touch. The runes ignite from the bottom up (ember, then flame, then gold) and the brazier lights.
- `prop_checkpoint_shrine_lit.png` 32×64 ×4 @8, looping. The runes pulse and the flame flickers. Pair it with the hero's `fx_<element>_respawn.png` on respawn.
- `prop_exit_arch.png` 64×96 ×4 @8, looping. A twisted-trunk archway with a rippling gold opening. The level-end trigger is the inner opening (x 15–48, y 20–94).

Anchor all props bottom-center on the ground.
