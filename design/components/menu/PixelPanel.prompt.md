Framed menu panel: stone bevel, notched ink outline, hard offset drop shadow and a recessed inner well. Used for pause, game over, level complete and dialog boxes.

```jsx
<PixelPanel title="Paused">
  <PixelButton variant="ghost" selected>Resume</PixelButton>
</PixelPanel>
```

- `tone`: stone (default), dark (over bright scenes), parchment (signs, lore, NPC text).
- Shadow is a solid 2-art-pixel ink offset; never blurred.
