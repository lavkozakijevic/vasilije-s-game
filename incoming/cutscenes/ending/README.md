# Ending cutscene

Four panels, 640×360, drawn at 320×180 and doubled, same layer rules as the intro (bg, chars, fx, plus title on 04).

- **ending_01_scarf**: bg, chars, fx. Suggested motion: slow push in toward Baba and Mrak; dust motes drift in the moonbeam
- **ending_02_kitchen**: bg, chars, fx. Suggested motion: slow pan left to right; steam rises from the cookies
- **ending_03_fireworks**: bg, chars, fx. Suggested motion: fireworks fx layer flashes burst by burst; kids run in place
- **ending_04_credits**: bg, chars, fx, title. Suggested motion: title layer fades in by dithered steps or slides up; stones pulse

The credits text is baked into `ending_04_credits_title.png`. If you need it localised or editable, render the text in-engine instead and skip that layer.
