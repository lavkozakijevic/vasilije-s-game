# Knight statues

`statue_knight_<element>.png`: 32×32 stone versions of the 8 Hearth Knights on a plinth, with the element emblem on the plinth. The knight stands 4px higher than in the hero sprites (feet at y 27) so the plinth fits.

`fx_statue_awaken.png` (32×32, 6 frames, 10 fps, once) is an overlay drawn over the statue: 0-2 glowing cracks, 3 flash (swap the statue for the hero idle here), 4-5 stone shards and dust.
